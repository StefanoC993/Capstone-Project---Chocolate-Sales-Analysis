
=============================================
CAPSTONE PROJECT - ANALISI DELLE VENDITE DI CIOCCOLATA: SWEET INSIGHTS FROM DATA
==================================================

DESCRIZIONE DEL PROGETTO
------------------------
Questo progetto esplora l'intero ciclo di vita dei dati delle vendite
di cioccolata: dalla pulizia iniziale alla modellazione predittiva,
fino alla visualizzazione strategica per il business.

STRUTTURA DEL REPOSITORY
------------------------
1. PRESENTAZIONE
   - PRESENTAZIONE PF GRUPPO 3: 
   Sintesi del lavoro svolto.

2. PREPARAZIONE DEI DATI
   - 1. Data Cleaning.ipynb: 
   Script per il preprocessing, gestione valori mancanti e normalizzazione.

2. ANALISI STATISTICA
   - statistica_finale Matteo.ipynb
   - statistica_finale eddy.ipynb
   Studio di medie, varianza e distribuzioni.
   
3. MACHINE LEARNING
   - ML final project - definitivo.ipynb:
   Implementazione di modelli di regressione per il forecasting delle vendite.

4. BUSINESS INTELLIGENCE & REPORTING
   - PowerBi Chocolate Sales 3-4-2026.pbix:
   Report interattivo Power BI.
   
TECNOLOGIE UTILIZZATE
---------------------
- Python 3.x (Pandas, NumPy, Matplotlib, Scikit-Learn)
- Power BI
- Microsoft PowerPoint

COME INIZIARE
-------------
1. Clonare il repository.
2. Installare le dipendenze: pip install -r requirements.txt
3. Esplorare i file seguendo l'ordine numerico sopra indicato.
   
NOTE
----
Progetto a scopo analitico. Creato per identificare i trend di
consumo e ottimizzare le strategie di vendita nel settore dolciario.
